# Phase 3E Temporal-Process Result

Phase 3E did not select a replay process. The reservation and final-evaluation gates remain closed.

The result is more informative than the earlier Phase 3D rejection. Increasing paired block lengths improved temporal fidelity, and the empirical-innovation VAR(1) met the temporal reference in four of five folds. The switching VAR(1) met it in three folds. Therefore, short-range temporal dependence is no longer the only blocker.

Every candidate, regardless of model class, met the joint-distribution reference in exactly the same two folds and failed it in the other three. Consequently, no candidate reached four folds of simultaneous joint and temporal support.

This common failure pattern suggests a cross-session distribution shift or an unattainable joint reference, rather than six independent model failures. That interpretation is not yet established. The next analysis must compare each real held-out development session directly with the real training sessions and with a holdout-fitted diagnostic oracle. The oracle is diagnostic only and cannot be selected as a replay process.
